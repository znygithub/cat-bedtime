# 产品设计的核心理念

Cat Bedtime / **猫猫困了**：到点后电脑要借给猫猫睡觉，用户也顺势离开屏幕。

## 背景

很多人不是不知道该睡觉，而是在电脑前很难完成「主动结束」。Cat Bedtime 把冷冰冰的屏幕管控换成更好接受的理由：用户不是在「被禁用电脑」，而是在兑现「让猫猫睡觉」的承诺。

## 核心体验原则

- **叙事优先**：温情约束，不是惩罚。
- **先提醒再锁住**：锁屏前有明确、可感知的收尾期（T-5 / T-1 强制 Toast + 亮度音量渐变）。
- **约束要可信**：多显示器覆盖；overlay 被杀后在锁屏窗内重新拉起。
- **异常有边界**：正式锁屏时段内不提供普通退出；ESC 仅提示或受控逃生。
- **App 与 CLI 同源**：同一份 `~/.timetosleep/` 语义，同一套 daemon 和 overlay。

## 产品边界

**负责：** 睡前提醒、按约定锁屏、起床后恢复。

**不做：** 番茄钟、任务管理、网站黑名单、全天候家长控制、账号云同步、多套锁屏实现。

## 阶段路线

**当前：** App onboarding + Dashboard + CLI `zzz`；单套 daemon + overlay；T-5/T-1 Toast；锁屏窗 `< 15h`。

**近期：** 保持双端配置契约；强化跨午夜、休眠、多显示器、无通知权限等场景测试；发布包资源完整。

**暂不做：** 账号系统、复杂游戏化、多套独立锁屏。
