# 设计系统

## 1. 设计目标

Cat Bedtime 的设计系统服务两个界面环境：

- APP 版本：macOS SwiftUI 窗口，负责 onboarding、dashboard、配置、请假和晚点。
- CLI 版本：终端交互，负责安装后的初始化、状态查看、配置、日志和卸载。

系统目标是让“猫猫睡觉”成为一致的产品语言，同时保证睡前工具的可靠、清晰和低打扰。

## 2. 品牌原则

| 原则 | 定义 | 设计含义 |
| --- | --- | --- |
| 温柔约束 | 不是惩罚用户，而是帮用户离开电脑 | 低攻击性的颜色、文案和动效 |
| 明确承诺 | 用户知道自己设置了什么，并知道何时生效 | 时间、天数、状态必须高可读 |
| 睡前安静 | 视觉降低刺激，不制造新的沉迷点 | 避免高饱和、强闪烁、复杂游戏化 |
| 到点坚决 | 锁屏阶段必须可信 | 锁屏 UI 不提供误导性的普通退出入口 |
| 双端一致 | APP 和 CLI 是同一个产品，不是两个工具 | 术语、状态和数据语义保持一致 |

## 3. 设计 Token

### 3.1 色彩

当前 APP 代码中的 `Lamp` enum 是实现侧 token 来源。新增设计必须优先映射到这些语义。

| 语义 | Token | Hex | 用途 | 对比要求 |
| --- | --- | --- | --- | --- |
| 深夜背景 | `nightDeep` | `#0F1613` | 锁屏背景、最深层窗口背景 | 仅承载浅色文本 |
| 主窗口面 | `nightSurface` | `#1A2320` | APP 主背景 | 主文本对比不低于 WCAG AA |
| 抬高层 | `nightElevated` | `#1D2A27` | 控件容器、popover、局部面板 | 与背景需可区分 |
| 月光强调 | `amberMoon` | `#F0C55E` | 主按钮、当前状态、关键时间 | 不用于大面积背景 |
| 信任色 | `tealTrust` | `#5AB5A5` | 启用、可继续、可保存 | 可与成功色区分 |
| 成功色 | `sageOk` | `#6CC28A` | 完成、已保存、已恢复 | 只表达结果 |
| 例外警示 | `clayWarn` | `#D97A68` | 今晚请假、风险提示、失败状态 | 不用于普通取消 |
| 主文本 | `creamText` | `#F2E3C3` | 标题、正文、时间数字 | 主文本默认色 |
| 次级文本 | `sandMuted` | `#B0A690` | 辅助说明、标签 | 不承载关键信息 |
| 弱提示 | `duskDim` | `#786F63` | placeholder、弱图标 | 避免单独表达状态 |
| 禁用线条 | `ashGhost` | `#48423A` | disabled、分隔线、背景图形 | 不用于可点击主状态 |

### 3.2 透明层

| Token | 值 | 用途 |
| --- | --- | --- |
| `glass1` | white 4% | 大面积轻分层 |
| `glass2` | white 7% | 默认控件底 |
| `glass3` | white 12% | hover、选中、强调底 |
| `borderSubtle` | white 6% | 非交互边界 |
| `borderDefault` | white 8% | 默认控件边界 |
| `borderHover` | white 14% | hover / focus 边界 |

### 3.3 字体

APP 使用 macOS system rounded：

| 层级 | 字号 | 字重 | 用途 |
| --- | --- | --- | --- |
| Display | 28-32 | Semibold | Onboarding 主标题 |
| Title | 20-24 | Semibold | Dashboard 页面标题、锁屏状态标题 |
| Section | 15-17 | Semibold | 区块标题、控件组标题 |
| Body | 13-15 | Regular | 正文说明、状态说明 |
| Caption | 11-12 | Regular | 辅助说明、时间单位、脚注 |
| Time | 34-44 | Semibold | 当前时间、睡觉/起床时间展示 |

CLI 使用终端默认字体，不控制字体族，只控制结构、颜色和符号。

### 3.4 圆角与尺寸

| 对象 | 圆角 | 说明 |
| --- | --- | --- |
| 主窗口内部面板 | 8 | 不使用大圆角卡片 |
| 按钮 | 8 | 保持 macOS 原生工具感 |
| 时间输入 / 分段按钮 | 6 | 稳定、紧凑 |
| popover | 8 | 可作为临时面板 |
| 锁屏信息条 | 8 | 低存在感，不遮挡猫猫主体 |

APP 窗口当前基准：

- Onboarding：`420 x 560`
- Dashboard：`520 x 600`

新增页面必须先定义固定或可推导的窗口尺寸，避免 SwiftUI ideal size 反向撑大窗口。

### 3.5 间距

使用 4pt 基础网格：

| Token | 值 | 用途 |
| --- | --- | --- |
| `space-1` | 4 | 图标与文字之间 |
| `space-2` | 8 | 紧凑控件内部 |
| `space-3` | 12 | 表单行间距 |
| `space-4` | 16 | 区块内部默认 |
| `space-5` | 24 | 页面主要区块 |
| `space-6` | 32 | Onboarding 大段落 |

## 4. 组件规范

### 4.1 按钮

| 类型 | 用途 | 视觉 |
| --- | --- | --- |
| Primary | 当前步骤唯一主操作 | `amberMoon` 背景，深色文字 |
| Secondary | 返回、取消、稍后 | `glass2` 背景，`creamText` |
| Destructive Soft | 今晚请假、删除配置 | 低饱和 `clayWarn`，不做高压红 |
| Icon Button | 关闭、编辑、刷新 | 使用系统符号或现有图标，必须有 tooltip 或可理解上下文 |

按钮文案最多 6 个汉字或 3 个英文词。超过时改为更短标签，并把解释放到旁边说明中。

### 4.2 时间控件

- APP 中睡觉/起床时间必须用明确可编辑控件，不用自由文本伪装。
- 时间展示统一 `HH:mm`。
- CLI 中时间输入接受 `H:mm` 或 `HH:mm`，存储统一 `HH:mm`。
- 时间错误应提示格式示例。

### 4.3 天数选择

- APP 使用 7 个等宽 toggle，顺序为一、二、三、四、五、六、日。
- CLI 使用多选列表，默认周一到周五。
- 选中态使用 `tealTrust` 或 `amberMoon`，未选中态保持可见边界。

### 4.4 状态卡片

状态卡片只用于承载一个独立信息，如“今晚睡觉时间”“起床时间”“连续完成”。不得把多个页面区块包进大卡片。

状态卡片结构：

1. 小标签。
2. 主要数值。
3. 一行辅助说明。

### 4.5 Popover / Sheet

用于短任务：

- 晚点再来。
- 今晚请假。
- 权限说明。

必须包含：

- 标题。
- 可完成任务的最少输入项。
- 取消和确认。
- 错误提示位置固定，避免布局跳动。

### 4.6 CLI UI

CLI 由 `lib/ui.sh` 统一输出。

| 元素 | 规范 |
| --- | --- |
| Header | 用短标题，不使用长段介绍 |
| Box | 用于欢迎、承诺摘要、今晚状态 |
| Prompt | 统一 `›` 提示符 |
| Success | 使用绿色和简短结果 |
| Warning | 使用黄色或暖色，说明用户可做什么 |
| Error | 明确失败原因和下一步命令 |

CLI 必须保持中文输入可编辑，不能破坏 readline 处理。

## 5. 页面规范

### 5.1 Onboarding

结构：

1. 欢迎和叙事。
2. 时间设置。
3. 启用日。
4. 承诺摘要。
5. 完成和预览。

每屏只做一件事。不要在 onboarding 首屏塞入 dashboard 信息。

### 5.2 Dashboard

首屏应直接回答：

- 今晚猫猫来不来。
- 几点来，几点走。
- 是否已经请假或晚点。
- 用户现在能做的两类例外操作：晚点再来、今晚请假。

Dashboard 不做营销介绍。

### 5.3 锁屏

锁屏 UI 分层：

1. 深夜背景。
2. 猫猫动画主体。
3. 低干扰状态信息：当前时间、剩余时间、猫猫睡觉提示。

正式锁屏不展示普通“关闭”按钮。预览模式可以有明确的测试退出路径。

## 6. 文案系统

### 6.1 术语

| 概念 | 推荐文案 | 避免 |
| --- | --- | --- |
| 初始化 | 领养猫猫 | 启用管控 |
| 睡觉时间 | 猫猫来睡 | 禁用开始 |
| 起床时间 | 猫猫离开 | 解锁时间 |
| 跳过 | 今晚请假 | 放弃、失败 |
| 延后 | 晚点再来 | 推迟惩罚 |
| 锁屏中 | 猫猫正在睡觉 | 电脑已被锁死 |

### 6.2 语气

- 肯定用户的计划，不评价用户自控力。
- 例外操作需要原因，但文案不羞辱。
- 错误提示必须包含下一步。

## 7. 动效系统

| 场景 | 动效 | 约束 |
| --- | --- | --- |
| Onboarding 转场 | 轻量淡入 / 位移 | 不超过 250ms |
| 控件反馈 | hover / press 透明度变化 | 不引起布局变化 |
| 睡前收尾 | 亮度和音量渐变 | 以 daemon 可靠性为准 |
| 锁屏猫猫 | 三幕动画 + 呼吸循环 | 不影响退出判断 |

禁止闪烁、强抖动、长时间吸引注意力的循环动效。

## 8. 可访问性

- 关键文本对比不低于 WCAG AA。
- 不只用颜色表达状态，必须有文字或图标辅助。
- 所有可点击元素最小命中区域不小于 `28 x 28`。
- 中文、英文、本地化长文本都必须验证不溢出。
- APP 固定窗口内不能出现按钮被挤出底部。

## 9. 实现检查

新增或修改 UI 时检查：

- 是否复用 `Lamp` token。
- 是否符合 APP / CLI 各自的组件规范。
- 是否避免卡片套卡片。
- 是否在窗口尺寸内验证中文和英文。
- 是否不会破坏 daemon 作为唯一提醒时机来源。
