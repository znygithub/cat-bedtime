# Product Sense

## 为什么做

到点了关不掉电脑——再回一条消息、再看一个 tab，时间就滑到深夜。Cat Bedtime 用一件温柔的事约束你：**电脑要借给猫猫睡觉**。

## 产品是什么

macOS 睡前锁屏工具：

1. 设定猫猫**几点来睡、几点离开、每周哪几天来**
2. 到点前提醒（强制 App Toast）、降亮度、降音量
3. 到点后全屏锁屏（透明猫猫动画），到起床时间自动恢复

## 给谁用

| 用户 | 版本 |
| --- | --- |
| 不想碰终端 | **App 版**（DMG） |
| 喜欢用命令行 | **CLI 版**（`zzz`） |

两版共用 `~/.timetosleep/`，选一个即可。

## 体验原则

- **温情而不是惩罚**：「猫猫要睡觉」，不是「你被禁用了」
- **一次领养，长期生效**：完成设置后每晚自动运行
- **可请假、可晚点**：但要说明原因；T-1 Toast 还可一次性推迟 5 分钟
- **锁得住**：多显示器；overlay 被杀会拉起

## 成功标准

- 新用户只看 README 就能选对版本并完成安装
- App：DMG → 领养 → 到点能锁屏
- CLI：`install.sh` → `zzz init` → `zzz` 能看状态
- 发布包签名/公证（维护者本地 `scripts/release-macos.sh`）
